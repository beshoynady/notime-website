# الأقسام المقصوصة: قبل وبعد (2026-11-20)

بلاغ المالك: في قسم «أربع خطوات، وخطة واحدة» يبقى جزء الخطوات مقطوعًا أسفل الشاشة.

## الفحص

- **أداة فحص الأقسام المثبّتة:** عند آخر لحظة من التثبيت، تقيس هل أعلى عنصر وأدنى عنصر ظاهران بين الترويسة وشريط الطلب.
- **الأقسام غير المثبّتة:** فحص لكل الصفحات (15 صفحة × 7 مقاسات × لغتين = 210 حالة). يبحث عن:
  - نص قصّه `overflow`؛
  - حركة ظهور لم تكتمل؛
  - آخر الصفحة تحت شريط الطلب.
- **النتيجة:** لا قصّ في الأقسام غير المثبّتة. الخلل محصور في الحالات الثلاث أدناه.
