## Performance: from ~58 to 90 on mobile (D111)

Measured 2026-11-16 (`docs/checkpoints/lighthouse/post-m3/after.json`): TBT 1.2–1.7 s and a simulated LCP of ~4.4 s, although the real LCP is the H1 at FCP (~1.5 s). The main thread is the cause; in order of expected gain:

1. **Scroll setup after idle.** Create the ScrollTriggers of sections below the fold on `requestIdleCallback` or on first scroll, and batch their measurements, so the ~2.6 s of style/layout (4× CPU) leaves the load window. Keep the still state in CSS so nothing shifts.
2. **Smaller hydration.** React spends ~3.3 s (4× CPU) hydrating; move static markup out of client components (pass it as server `children`), and hydrate below-fold islands on visibility.
3. **Motion only where it is used** above the fold; load the rest with the island.
4. **Per-theme CSS.** Every category page inlines all four themes (≈ 82 KB raw); split them when the category route is split by theme.
5. Re-measure with medians of 3 on a quiet machine; report the benchmark index with every run.
