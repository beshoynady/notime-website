# رسالة راند: الصور (واتساب)

للمالك: الرسالة أدناه جاهزة للنسخ كما هي. مصدر القائمة: الصور المؤقتة في `images-for-rand.md` وقائمة الملفات المطلوبة في `src/content/media-wanted.ts`. رتّبتُ الصور من الأهم: صفحة الفعاليات أولًا لأنها أكثر صفحة تعرض صورًا مؤقتة، ثم افتتاحيات الصفحات، ثم أقسامها. الرابط هو رابط المعاينة العام على Vercel، ويفتح دون تسجيل دخول.

---

مرحبًا راند،

هذه معاينة الموقع: https://notime-website-ashen.vercel.app/ar

بعض الصور في الموقع أخذناها مؤقتًا من مكتبات صور مجانية، وسنضع مكانها صوركم فور وصولها. نحتاج منكِ 12 صورة، مرتبة من الأهم:

1. قاعة مؤتمر جهّزتموها، لقطة واسعة قبل دخول الضيوف ← صفحة الفعاليات ← 2000 بكسل عرضًا على الأقل
2. مسرح في إحدى فعالياتكم والأضواء تعمل، والجمهور من الخلف ← صفحة الفعاليات ← 2000 بكسل
3. قاعة معرض أو جناح من تنفيذكم قبل افتتاح الأبواب ← صفحة الفعاليات ← 2000 بكسل
4. الصور الأصلية لجناح مصر للطيران ← صفحة أعمالنا والصفحة الرئيسية ← 1600 بكسل
5. استوديو أو موقع تصوير جهّزتموه، دون أشخاص ← افتتاحية صفحة الإنتاج الإبداعي ← 2000 بكسل
6. مكتب الفريق أثناء العمل على حملة، دون وجوه ← افتتاحية صفحة التسويق ← 2000 بكسل
7. الورشة أو قسم الطباعة أثناء العمل على طلب حقيقي ← افتتاحية صفحة الإنتاج والطباعة ← 2000 بكسل
8. هوية صمّمتموها مطبوعة على أوراق ومطبوعات حقيقية ← صفحة التسويق، قسم الهوية ← 1600 بكسل
9. شاشات من موقع أو تطبيق نفّذتموه (بموافقة العميل) ← صفحة البرمجيات ← 1600 بكسل
10. معدّات التصوير والإضاءة التي تؤجّرونها، دون شعارات ظاهرة ← صفحة الإنتاج الإبداعي، قسم التأجير ← 1600 بكسل
11. صندوق جوائز دوري المحترفين دون علامة «2 of 3» ← صفحة الإنتاج والطباعة، قسم التغليف ← 1600 بكسل
12. أجنحة Smith Gulf بحجمها الأصلي ← صفحة الإنتاج والطباعة، قسم تصنيع الأجنحة ← 1600 بكسل

صورة الهاتف الحديث بحجمها الأصلي تكفي. أرسليها كملفات (مستند) لا كصور، لأن واتساب يصغّر الصور.

وإن كانت لديكم ملفات الفيديو الأصلية لأعمال الموشن جرافيك، فأرسليها كما هي، لتظهر في صفحة الإنتاج الإبداعي.

وأخيرًا: إن رأيتِ في الموقع أي صورة لا تريدين ظهورها، أرسلي لي لقطة شاشة لها أو اسم الصفحة، وأحذفها.

شكرًا لكِ.
